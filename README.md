# SelfCRMlanding

Статичный лендинг SelfCRM: https://doc9830.github.io/SelfCRMlanding/

Страница рассказывает про текущую версию приложения: сейчас это **1.3.1** (напоминания по заказам и блок напоминаний на главном экране). При выпуске новой версии обновляются номер и ссылка на APK в `<head>` (meta, JSON-LD), кнопка в hero, подпись «Версия … · Android · APK …», шаг 01 в «Установке» и скриншоты.

## Что внутри

- `index.html` — единственная страница: hero с живым демо экранов, возможности, «бесплатно», поддержка, установка. Тема (светлая/тёмная) переключается кнопкой и запоминается в `localStorage`.
  - Hero собран так, чтобы в первый экран ноутбука влезали сразу: кадр приложения, кнопки-табы под ним, ссылки «Скачать APK» / GitHub и карточка «Сейчас на экране».
  - Ширина кадра привязана к высоте окна: `--phone-w: min(520px, calc((100dvh - 300px) * .784 + 22px))` (на низких окнах — `min(460px, …)`, на `min-height: 1000px` — до 560px, при `max-width: 1120px` — до 440px). Поэтому демо и описание не уезжают за сгиб ни на 1366×768, ни на 1280×720, ни на 1366×640; на 1440×900 и выше кадр показывается в полный размер (масштаб ~0.91–1.05 CSS px на 1 dp приложения).
  - Рамка тонкая, скругление симметричное: 26 px снаружи и 16 px у самого скриншота (без «капли» снизу).
  - Клик по экрану открывает скриншот в лайтбоксе во всю доступную высоту (до 660 px в ширину, без апскейла); закрывается по Esc, клику по фону и по крестику.
- `Screenshots v3/` — 13 экранов приложения в двух темах, 26 PNG (660×842, PNG8, ~1 МБ всего). Имена файлов: `Экран (светлый|темный).png`. Кадры сняты с версии 1.3.1.
- `og-cover.png` — обложка 1200×630 для соцсетей и мессенджеров (`og:image`): градиент, крупная надпись, телефон с кадром главного экрана (439×560 в точке 713×35, радиус 21) и строка версии (DejaVu Sans 22, цвет #93C5FD).

## Как обновить скриншоты

Кадры снимаются прямо из приложения (репозиторий [SelfCRM](https://github.com/doc9830/SelfCRM)) через headless Chrome:

0. Демо-состояние для съёмки (важно: на кадрах должны быть адрес клиента, архив и история склада). В dev-режиме: «Настройки → Демо-данные → Заполнить», затем вручную — адрес «тверская 1» для Ивана Петрова (первая подсказка), Светлана Орлова в архив, приход кофе +10 с комментарием «Закупка у поставщика» на экране «Склад → Кофе в зёрнах».
1. Запустить dev-сервер приложения: `npm run dev -- --port 5199 --strictPort`.
2. Запустить Chrome с отладочным портом: `google-chrome --headless=new --remote-debugging-port=9222 --user-data-dir=/tmp/landing-chrome`.
3. Снять все экраны в двух темах скриптом-съёмщиком (CDP, кадр 515×657 при DPR 2, тема — через `localStorage['selfcrm:theme']`), пройдя по маршрутам приложения: главная, клиенты, архив, карточка клиента, подсказки адреса (форма правки + ввод «тверская 1»), заказы, заказ в работе, завершённый заказ, товары, карточка товара (модальное окно), склад, движение товара, изменение остатков (количество 5 и комментарий «Новая партия», без применения).
4. Уменьшить кадры до 660×842 (Lanczos) и сохранить PNG8 (`quantize(256, MEDIANCUT)`, `optimize=True`), затем положить в `Screenshots v3/`.
5. Обновить строку версии на `og-cover.png`: затереть надпись, восстановив градиент интерполяцией между строками фона, и нарисовать новую строку (DejaVu Sans 22, `anchor='ls'`, левый край 74, базовая линия 507); кадр на телефоне — новый `Главный экран (темный).png` под маской со скруглением 21.
