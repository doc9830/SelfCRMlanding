# SelfCRMlanding

Статичный лендинг SelfCRM: https://doc9830.github.io/SelfCRMlanding/

## Что внутри

- `index.html` — единственная страница: hero с живым демо экранов, возможности, «бесплатно», поддержка, установка. Тема (светлая/тёмная) переключается кнопкой и запоминается в `localStorage`.
  - Hero собран так, чтобы в первый экран ноутбука влезали сразу: кадр приложения, кнопки-табы под ним, ссылки «Скачать APK» / GitHub и карточка «Сейчас на экране».
  - Ширина кадра привязана к высоте окна: `--phone-w: min(520px, calc((100dvh - 300px) * .784 + 22px))` (на низких окнах — `min(460px, …)`, на `min-height: 1000px` — до 560px, при `max-width: 1120px` — до 440px). Поэтому демо и описание не уезжают за сгиб ни на 1366×768, ни на 1280×720, ни на 1366×640; на 1440×900 и выше кадр показывается в полный размер (масштаб ~0.91–1.05 CSS px на 1 dp приложения).
  - Рамка тонкая, скругление симметричное: 26 px снаружи и 16 px у самого скриншота (без «капли» снизу).
  - Клик по экрану открывает скриншот в лайтбоксе во всю доступную высоту (до 660 px в ширину, без апскейла); закрывается по Esc, клику по фону и по крестику.
- `Screenshots v3/` — 13 экранов приложения в двух темах, 26 PNG (660×842, PNG8, ~1 МБ всего). Имена файлов: `Экран (светлый|темный).png`.
- `og-cover.png` — обложка 1200×630 для соцсетей и мессенджеров (`og:image`).

## Как обновить скриншоты

Кадры снимаются прямо из приложения (репозиторий [SelfCRM](https://github.com/doc9830/SelfCRM)) через headless Chrome:

1. Запустить dev-сервер приложения: `npm run dev -- --port 5199 --strictPort`.
2. Запустить Chrome с отладочным портом: `google-chrome --headless=new --remote-debugging-port=9222 --user-data-dir=/tmp/landing-chrome`.
3. Снять все экраны в двух темах скриптом-съёмщиком (CDP, кадр 515×657 при DPR 2), пройдя по маршрутам приложения: главная, клиенты, архив, карточка клиента, подсказки адреса, заказы, заказ, товары, карточка товара, склад, движение товара, изменение остатков.
4. Уменьшить кадры до 660×842 (Lanczos) и сохранить PNG8 (`quantize(256, MEDIANCUT)`, `optimize=True`), затем положить в `Screenshots v3/`.
